# Tecnologías del proyecto — Ruliette

> Guía: [Tecnologías del proyecto](../evaluacion/guias/fase-1-requerimientos/04-tecnologias.md)

## Stack

| Área | Herramienta | Para qué la uso |
|---|---|---|
| Construcción | HTML + CSS | Estructuración del contenido del sitio y definición del diseño visual responsivo. |
| Versionado | Git y GitHub | zona de control de cambios del código y alojamiento del repositorio. |
| Publicación | GitHub Pages | Despliegue en línea del sitio web para su acceso público. |
| Diseño | Whimsical | Creación del mapa de sitio y wireframes. |
| Diseño | Google Stitch | Generación e integración de prototipos visuales y recursos gráficos. |
| IA | Antigravity AI | Asistente de IA para la redacción, estructura y resolución de errores en el codigo. |
| Editor | Antigravity IDE | Entorno de desarrollo para la edición de código, gestión de archivos y ejecución de terminal Git. |

## Qué es funcional y qué es prototipo

| Funcionalidad | Estado en esta versión |
|---|---|
| Estructura HTML y estilos CSS de la Landing Page | Funcional |
| Navegación entre secciones (Inicio, Sobre mí, Galería, Contacto) | Funcional |
| Formulario de contacto y suscripción | Prototipo visual |
| Catálogo de fotografías con filtros por categoría | Prototipo visual |
| Carrito de compras y pasarela de pago | Prototipo visual |
| Vista previa de enmarcado interactivo | Prototipo visual |

## Integraciones para una versión real

- **Pasarela de pagos:** Integración con Transbank / Webpay o Mercado Pago para procesar compras con tarjetas de débito y/o crédito.
- **Sistema de envíos:** Conexión con Starken, Chilexpress, Blue Express para el cálculo automático de despachos a todo Chile.
- **Formulario backend / CRM:** Integración para recibir mensajes directos y gestionar altos volúmenes de clientes.

## Restricciones

- **Plazo:** Fecha límite de entrega fijada según el calendario de entregas.
- **Marca:** Uso estricto de la paleta de colores, tipografías e identidad visual enfocada en fotografía de naturaleza orgánica y sustentable.
- **Dispositivos:** El sitio debe ser completamente responsivo, adaptándose a teléfonos móviles, tablets y computadores de escritorio.
